# scv-pine-script

SCV TradingView Pine Script — 选股系统三大成分：

| 成分 | 说明 | 文件 | 状态 |
|------|------|------|------|
| **SCV 合并版** | Stage + Contraction + Volume 一个指标全包（主图） | `scripts/SCV_All.pine` | ✅ 推荐使用 |
| **S** — Stage | 以 150 均线判断 Stage 1~4 阶段 | `scripts/SCV_Stage.pine` | ✅ 完成 |
| **C** — Contraction | VCP 式收缩形态 C1~C6、Base 突破、买点 | `scripts/SCV_Contraction.pine` | ✅ 完成 |
| **V** — Volume | 结构量能、突破放量、流动性、烛数加分（副图，含成交量柱） | `scripts/SCV_Volume.pine` | ✅ 完成 |

## 使用方法

1. 打开 TradingView → Pine Editor
2. 复制 `scripts/SCV_All.pine` 的内容贴上（或按需使用单独的 S / C / V 脚本）
3. 点「Add to chart」

> 合并版是主图指标，成交量直方图请开 TradingView 内建的成交量；
> 放量突破以K线上方圆点标记。想要带颜色的成交量柱可另外加载 `SCV_Volume.pine`。

## Stage 规则摘要

- **Stage 1**：150均线趋平 · 横盘至少半年 · 交易量低迷 → 不交易
- **Stage 2**：150均线趋上 · 阳烛量放大 → 做多时期
- **Stage 3**：150均线趋平 · 阴烛量放大 · 跌穿150均线 → 不交易
- **Stage 4**：150均线趋下 → 做空时期

均线颜色：50均线 灰色 · 150均线 绿色 · 200均线 红色

## 排错清单（Troubleshooting）

代码只能在 TradingView 的 Pine Editor 里编译。贴上去点「Add to chart」后，
如果出问题，先对照下面这张表。**改不动就把红色错误那一行整句复制发出来。**

### A. 编译报错（编辑器下方出现红字，图上没东西）

| 报错长这样 | 意思 / 怎么改 |
|-----------|-------------|
| `Mismatched input '<something>' expecting <...>` | 复制粘贴时**少贴了几行或多贴了字符**。删掉指标重贴一次整份文件，注意第一行 `//@version=6` 一定要在最顶端。 |
| `Could not find function or function reference 'xxx'` | TradingView 账号的 **Pine 版本被切成旧版**。确认第一行是 `//@version=6`；这套脚本用的是 v6 语法。 |
| `The 'plot' ... cannot be used in a local scope` | 说明贴的时候某个 `plot` 被误缩进了。所有 `plot / bgcolor / plotshape` 必须顶格（不能在 `if` 里）。重贴整份即可。 |
| `line X: Syntax error at ...` 且 X 是中文那几行 | 极少数情况编辑器对全角标点敏感。把那一行的**中文括号 `（）` 或标点**先不用管——通常是复制时把 tab/空格弄乱了，重贴一次。 |
| `Script requesting too many securities` | 你把 RS 对比指数或大小周期设成了太多不同 symbol。保持默认即可（RS 用 `SP:SPX`，大小周期用 `D` 和 `60`）。 |

### B. 能加载但显示不对

| 症状 | 原因 / 怎么调 |
|------|-------------|
| **图左边一大段没有均线 / 面板显示「新图」** | 这只票K线数不够算 200 均线（新股）。按规则应该**去看 4 小时图**：把设置「④ 大小周期 → 大周期」改成 `240`。这是正常行为，不是 bug。 |
| **Stage 一直乱跳 / 太敏感** | 「② Stage → 趋平阈值」调大（例如 1.5~2），或「150均线斜率回看K线数」调大（例如 30）。波动大的票需要更大的阈值。 |
| **完全侦测不到 Contraction（C 段数一直 0）** | ① 当下不是多头/空头排列（无排列时 C 会暂停，面板会写「无排列」）。② 「⑤ Contraction → 摆动强度」太大，抓不到波段，调小（例 3~5）。 |
| **C 段太多/太碎，和手画的对不上** | 「⑤ → 摆动强度」调大（例 8~10）只抓大波段；或「最小波段深度」调大（例 5%）过滤小杂讯。 |
| **C1 老是被判「未动到50均线」** | 「⑤ → 50均线触碰容差」从 2 调大到 3~4（%）。 |
| **RS 一直显示「中性」** | 对比指数和你的股票不同市场（例如美股配了港股指数）。把「③ → 对比指数」换成对应大盘（美股 `SP:SPX`，港股 `HSI`，A股 `SSE:000001` 等）。 |
| **大小周期永远「不同向」** | 你开的图表周期**比小周期还小**（例如开 15 分钟图，小周期设 60）。把图表切到天图看，或把小周期设得比当前图表大。 |
| **成交量柱看不到颜色** | 合并版是主图指标，没有成交量柱。要彩色量柱另外加载 `SCV_Volume.pine`（副图）。 |

### C. 面板 / 标签相关

| 症状 | 说明 |
|------|------|
| **右上角面板挡住价格** | 指标设置 → 面板目前固定右上角。可以在「⑦ 面板」把不看的区块（S/C/V）关掉缩短它。 |
| **标签太多、图很乱** | 正常，历史上每个 C 段和每次 Base 突破都会留标签。可在指标设置里关掉「显示 C1 三等份区域」减少干扰。 |

### 反馈 bug 的最快方式

1. **编译错**：复制红色那行的**完整文字**。
2. **判断不对**：给出 **股票代码 + 时间框架 + 日期 + 期望值 vs 实际值**
   （例：「`AAPL` 天图 2024-03，这里应是 Stage 2，指标却显示 Stage 3」）。
