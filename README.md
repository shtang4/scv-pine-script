# scv-pine-script

SCV TradingView Pine Script — 选股系统三大成分：

| 成分 | 说明 | 文件 | 状态 |
|------|------|------|------|
| **SCV 合并版** | Stage + Contraction + Volume + 选股 + 买点/止损/卖出 一个指标全包（主图） | `scripts/SCV_All.pine` | ✅ 推荐使用 |
| **S** — Stage | 天图 150 均线判断 Stage 1~4 阶段 | `scripts/SCV_Stage.pine` | ✅ 完成 |
| **C** — Contraction | C1~C6 收缩、Base 突破、买点（摆动点 / 数蜡烛 两种切段方式） | `scripts/SCV_Contraction.pine` | ✅ 完成 |
| **V** — Volume | 结构量能、突破放量、流动性、烛数加分（副图，含成交量柱） | `scripts/SCV_Volume.pine` | ✅ 完成 |

## 使用方法

1. 打开 TradingView → Pine Editor
2. 复制 `scripts/SCV_All.pine` 的内容贴上（或按需使用单独的 S / C / V 脚本）
3. 点「Add to chart」

> 合并版是主图指标，成交量直方图请开 TradingView 内建的成交量；
> 放量突破以K线上方圆点标记。想要带颜色的成交量柱可另外加载 `SCV_Volume.pine`。

## Selection 选股（面板最上面两行）

三个成分各找一样东西，**看它们的交集下结论**：

| 成分 | 找什么 | 判定条件 |
|------|--------|---------|
| **S** | 找**动能** | 天图 Stage 与当前周期排列同向（= 可交易 S+） |
| **C** | 找**买点** | 结构成立（≥2 段）**且** 末段收缩 ≤ 买点% |
| **V** | 找**流动性** | **过去 24 小时**交易金额 ≥ 门槛（默认 100 万）；日均那项只当参考显示 |

| 组合 | 结论 | 意思 |
|------|------|------|
| **S + C + V** | ✅ **有大庄** | 三样齐全，最好的机会 |
| 只有 **S + C** | ⚠️ **调仓位** | 流动性不足 → 减小仓位 |
| 只有 **S + V** | ⏳ **等买点** | 动能和流动性都有，还没到买点 |
| 只有 **C + V** | ⚠️ **调低盈亏比** | 大方向没动能 → 降低盈亏比预期 |
| 其他 | ⛔ 不合格 | 只有一项或都没有 |

面板显示：`SCV 选股  ✅ 有大庄 · S+ C+ V+`

> 只有合并版 `SCV_All.pine` 有这两行——单独的 S / C / V 脚本各只有一个成分，凑不出交集。

## 周期怎么用（重要）

**大方向看天图 Stage，进场看小周期结构。**

| 项目 | 用哪个周期 |
|------|-----------|
| **Stage 1~4** | 固定**天图**（天图无150均线的新币/新股 → **自动切 4 小时**） |
| **大小周期同趋势** | 天图 vs **当前图表**（面板显示 `D vs 60`、`D vs 15`…） |
| **多头/空头排列** | **当前图表**（面板显示 `多头排列（60）`） |
| **Contraction 结构**（C1~C6、买点、Base） | **当前图表** |
| **Volume 结构量能、突破放量** | **当前图表** |
| **日均交易金额** | 固定天图（永远是真实日金额，不受图表周期影响） |

所以切换 1h / 30m / 15m 时，**Stage 不会变**，变的是排列和收缩结构。

## Stage 规则摘要

- **Stage 1**：150均线趋平 · 价格在均线上面 · 交易量低迷 · 横盘至少半年 → 不交易（详见下方）
- **Stage 2**：150均线趋上 · 阳烛量放大 · 有强度 → 做多时期（详见下方）
- **Stage 3**：150均线趋平 · 价格跌穿150均线 · 阴烛量放大 → 不交易（详见下方）
- **Stage 4**：150均线趋下 · 价格在均线下 · 越跌越陡（延续性强）→ 做空时期（详见下方）

### Stage 1 的四个条件（面板「Stage 1 条件」逐项打勾）

全部在**天图**上看 **150 均线**：

| # | 条件 | 程序怎么判 |
|---|------|----------|
| ① | **150 均线趋平** | 均线在回看期（默认 20 根）内变动 < ±1%（趋平阈值可调）。等同于把鼠标十字线放上去，均线跟虚线一样平 |
| ② | **价格在 150 均线上面** | 收盘价 > 150 均线 |
| ③ | **交易量低迷** | 当根量 **< 50 交易量均线**（就是量柱在那条橙线之下） |
| ④ | **横盘至少半年** | **≥ 180 日历天**（不是K线根数）。从一个**明显高点**算起，只要价格没有超过该高点 ×(1+容差 3%)（涨不上去、突破不上）就一直累计；一旦明显突破 → 区间重设、天数归零 |

> **为什么用日历天数不用K线根数**：股票一周 5 根、币一周 7 根，根数会差很多。用日历天数跟 TradingView 量尺显示的 `286d` 是同一个口径。**门槛是「至少半年 = 180 天」**，量尺量出 286d 只是那个例子的实际值，不是要求。
>
> 参数在「② Stage」组：**Stage 1 横盘最少天数**（180）、**Stage 1 横盘容差 (%)**（3）。

### Stage 2 的三个条件（面板「Stage 2 条件」逐项打勾）

同样在**天图**上看 **150 均线**：

| # | 条件 | 程序怎么判 |
|---|------|----------|
| ① | **150 均线趋上** | 均线在回看期（默认 20 根）内涨幅 > +1%（趋平阈值可调） |
| ② | **阳烛量放大** | 阳烛的量 **超过 50 交易量均线**；且回看期内这种**放量阳烛比放量阴烛多** |
| ③ | **强度（交易量 & 速度）** | 价格在均线**上面**，**离 150 均线越远强度越大**、持续性越强。面板显示乖离 %，超过「Stage 2 强度门槛」（默认 10%）标「强」 |

> 强度只是**显示强弱**，不会因为乖离小就把 Stage 2 判成不成立 —— 趋上 + 阳烛量放大 + 价在线上 三项齐了 Stage 2 就成立。
>
> 参数在「② Stage」组：**Stage 2 强度门槛 (%)**（10）。

### Stage 3 的三个条件（面板「Stage 3 条件」逐项打勾）

Stage 3 是 **Stage 2 涨完之后转下来**的阶段（趋上 → 趋平 → 跌穿），同样看**天图** **150 均线**：

| # | 条件 | 程序怎么判 |
|---|------|----------|
| ① | **150 均线趋平** | 均线在回看期（默认 20 根）内变动 < ±1%（Stage 2 涨完走平） |
| ② | **价格跌穿 / 在 150 均线下面** | 收盘价 < 150 均线；本根刚跌穿会标「（本根跌穿）」，图上另有橙色 ✕ 标记 |
| ③ | **阴烛量放大** | 阴烛的量 **超过 50 交易量均线**；且回看期内这种**放量阴烛比放量阳烛多**（阴烛越来越多） |

> Stage 3 = Stage 2 的镜像：趋上→趋平、阳烛量放大→阴烛量放大、价在线上→价在线下。

### Stage 4 = 做空时期（面板「Stage 4 条件」）

同样看**天图** **150 均线**：

| # | 条件 | 程序怎么判 |
|---|------|----------|
| ① | **150 均线趋下** | 均线在回看期（默认 20 根）内跌幅 > 1% —— **一进入趋下就是 Stage 4** |
| ② | **价格在 150 均线下面** | 收盘价 < 150 均线 |
| ③ | **延续性（越跌越陡）** | 均线从「慢慢趋下」变成「**垂直趋下**」= 下跌延续性强。面板显示均线跌幅%，超过「Stage 4 陡度门槛」（默认 8%）标「垂直趋下·延续性强」，否则标「慢慢趋下」 |

**Stage 4 什么时候结束**：一路跌到 **150 均线开始趋平** → Stage 4 结束，**周期循环**回 Stage 1（状态机自动切换，不用另外设定）。

> 陡度只是**显示延续性强弱**，不会因为跌得不够陡就把 Stage 4 判成不成立 —— 趋下 + 价在线下 就是 Stage 4。
>
> 参数在「② Stage」组：**Stage 4 陡度门槛 (%)**（8）。

**Stage 3/4 附加信号**
- **清仓**：距周期高点回落 ≥ 35%（股票/加密；其他资产改 10）→ 图上红色「清仓」三角
- **波动大不创新高**：ATR 高于均值 且 N 根没创新高 → 橙色菱形

### 可否交易（天图 Stage × 当前周期排列）

| Stage | 排列 | 面板显示 |
|-------|------|---------|
| 1 / 3 | 任何 | ⛔ 不交易 (S) |
| 2 | 多头 | ✅ **可交易 (多 S+)** |
| 2 | 空头 | ⛔ 不交易 (多 S-) |
| 4 | 空头 | ✅ **可交易 (空 S+)** |
| 4 | 多头 | ⛔ 不交易 (空 S-) |

### 均线排列（可切换严格度）

排列是**找 C1 的先决条件**，也决定做多还是做空。「① 均线 → **多头/空头排列定义**」两选一：

| 模式 | 多头排列 = | 效果 |
|------|-----------|------|
| **宽松：150>200**（默认） | 只要 **150 在 200 上** | 50 的位置不影响排列成立，只决定扣分档次。**C1 可以早一点开始** |
| **严格：50>150>200** | **50 最上 · 150 中间 · 200 最下**（完美排列） | 教材定义。**C1 出现得晚、数量少**，但每个都更干净 |

空头排列镜像（宽松：150 在 200 下；严格：50<150<200）。面板的「均线排列」那行会标出当前是「严格」还是「宽松」。

**扣分三档**（两种模式都照常扣，只影响 S 加分）：

| 50 的位置 | 判定 |
|-----------|------|
| 50 在 150 和 200 之上 | 完美，不扣分 |
| 50 在 150 下、仍在 200 上 | 小扣分（默认 −1） |
| 50 在 150 和 200 都下 | 大扣分（默认 −2） |

**均线颜色**：50均线 灰色 · 150均线 绿色 · 200均线 红色（三条都要开，每个周期都会画）

## 蜡烛分三种（S / C / V 全部共用这个定义）

先看**身体**和**影线**谁大 —— 不用去记 doji / hammer / shooting star 那些名字：

```
身体 (body)     = |收盘价 − 开盘价|
影线合计 (wick) = 整根范围(高−低) − 身体
```

| 蜡烛 | 判定 | 例子 |
|------|------|------|
| **变盘线** | **影线合计 > 身体**（**不管阴阳**） | 身体 30% / 影线 70%；十字线、锤子、射击之星…全都算 |
| **阳烛** | 身体 > 影线合计 **且** 收 > 开（青色） | 身体 70% / 影线 30% 的青烛 |
| **阴烛** | 身体 > 影线合计 **且** 收 < 开（红色） | 身体 70% / 影线 30% 的红烛 |

> **重点**：一根青色但影线很长的蜡烛 **不算阳烛**，它是**变盘线**。
> 所以 V 的「阳烛量大」、Stage 2 的「阳烛量放大」、Stage 3 的「阴烛量放大」、V 加分的烛数
> **都不会把变盘线算进去**；C 的「数蜡烛」侦测则是把**阴烛和变盘线一起数**。
>
> 门槛可调：「变盘线：实体 < K线范围 (%)」默认 **50%**（即影线 > 身体）；调低会更严格。

## Contraction 规则摘要

**先决条件：要先有多头排列，才能开始找 C1**（排列的严格度可切换，见上面「均线排列」）。

**一段 C 怎么算成立**（每段 C = 一段**上涨后的回调**）：
1. 找一个**明显的高点**和一个**明显的低点**（从左边最高价画到右边最低价，箭头一定向下），深度 =（高−低）÷ 高
2. 高低点**中间一定要有连续 3 根「阴烛 / 变盘线」的组合**
   - `阴阴阴`、`阴变阴`、`变变变`、`阴阴变`… 全都成立
   - **`阴阴阳` 不成立** —— 中间夹一根阳烛就断了

- **C1 额外要求**：必须**动到 50 均线**（跌破、甚至碰到 150 均线都可以）。**C2~C6 不用再看 50 均线**
- **C2~C6 两个条件都要**：**波段越缩越小**（每段比上一段浅）+ **底部越抬越高**（低点逐个抬高）
  - 例：C1 15% → C2 11% → C3 7%；底部 243.7 → 249.1 → 254.14
  - 低点抬高了但没缩小 → 结构作废，那一段当作新的 C1 重新开始（可在设置关掉缩小要求）
- 结构 = 2~6 段（C1~C6）
- **买点**：出现在 **C2~C6 之间**，而且那一段 C 要 **≤ 10%**；挂单挂在**那段 C 的最高点**
  - 例：C2 = 8.47% ≤ 10% → 可以在 C2 的高点挂单；错过了，C3 = 5.56% ≤ 10% → 在 C3 的高点挂
- **Base** = 突破 C1 高点

### 侦测方式（设置里二选一）

两种方式的高低点**都取真实峰谷价**，级联规则、加分扣分、画框完全一样，
差别只在「**一段收缩什么时候算结束**」：

| 方式 | 切段触发 | 专属参数 |
|------|---------|---------|
| **数蜡烛**（默认，= 教材对 C 的定义） | 段内出现连续 3 根 阴/变，且低点已确认 | 变盘线实体%、低点确认K线数 |
| **摆动点**（比较宽松） | 反向摆动点（swing high/low）确认 | 摆动强度 |

**数蜡烛的判定细则**

- 三种蜡烛的定义见上面「**蜡烛分三种**」（阳 / 阴 / 变盘线）
- 做多数 **阴/变**，做空数 **阳/变**
- 只要有**至少一组连续 3 根**就成立，**在开头 / 过程 / 结尾都算**
- 阴和变**各几根都无所谓**：`阴阴阴`、`阴阴变`、`阴变阴`、`变阴阴`、`变变变`、`变阴变`、`阴变变` 全都算
- **第一根同时是最高和最低也成立**（做出高点那根本身就可以是连续 3 根的第 1 根）

**一段摆动走完时怎么归位（按优先级）**

1. **低点抬高 + 波段缩小** → 新的一段（不管它的高点比上一段高还是低）
2. **低点没抬高，但高点突破了上一段高点**（且未破 C1 高点）→ 用这段的**高和低**重写上一段
3. **低点跌破上一段低点** → 低点级联并入前面那段（保留该段高点）

**低点 vs 高点的差别（重要）**
- **低点是实时的（但高点一被突破就定格）**：还没突破该段高点前，任何一根 K 跌破该段低点 → 立刻延伸该段低点。**一旦该段高点先被突破**（进入下面的 `C?` 阶段），该段低点**就此停在当时的最低点**，不再实时更新——之后再出现的更低点属于正在形成的新段，不算进旧段。
- **所有 C 的低点永远跟 C1 低点对查**：只要 **C1 高点还没被突破**，任何一段之后出现的低点只要**跌破 C1 低点，就直接变成 C1 的新低点**（一路并回 C1，即使中间某段的高点曾被突破过也照并）。
- **高点也是实时的，但要等新 C 才「转正」**：价格突破某段高点的当下，**已确认的旧段暂时仍然有效**（不马上改），同时把正在形成、还没成形的新一段用**橙色虚线框「C?」**标出来。等这段完整摆动走完（`legEvent` 触发）、按上面的规则真正成形，`C?` 才变成正式的 `C`。
- **C1 高点被突破 → C1 不再成立**：这属于 **Base 突破**（不画 `C?`）。原来的 C1/C 结构就此结束（≥2 段的留作历史纪录），之后从新高重新数下一个 base。
- **每段 C 的低点一定在它的高点「之后」**：低点 = 从该段高点往后追踪到的反向极值。所以当某段的高点被更高的高点改写（`C?` 转正）时，新低点也一定取**新高点之后**的低点，早于新高点的旧低点作废。

**Pivot Area / Cheap / Low Cheap** = 把 C1 深度切 3 等份（做多：顶部 = Pivot Area）

**加分（满分 10）**
1. 波段收缩合理：每段落在「前段一半 ± 1%」之内 **+3**
2. C1 深度在 20~35% **+3**（超出范围只是没这 3 分，**C1 仍然成立**）
3. Base 还在第 1 或 2 个 **+2**
4. 突破区域 = Pivot Area **+2**

**扣分（不并进总分，只显示提醒）**：C1 低点跌到 200 均线 → ⚠️ 太深太弱

**Base 计数**：从 Stage 2 开始数（做空从 Stage 4）；跌穿前一个 Base 低点，或退回 Stage 4/1 → 归零

## Volume 规则摘要

**大前提：只看「超过 50 交易量均线（橙线）」的蜡烛，橙线以下的一概忽略不计。**
**而且阳烛/阴烛都要「实体大过影线合计」才算数 —— 变盘线两边都不计**（见上面「蜡烛分三种」）。

- **① 阳烛量大**（做空镜像）：把**放量阳烛的量加总** vs **放量阴烛的量加总**，前者 > 后者 ×1.2 就成立
  - 统计区间：**已经有 C1 → 从 C1 起点算到现在**（C1~C6 整个 base 期间）；还没有 C1 → 退回用固定回看期（20 根）
  - 放量阳烛量特别大 = 好现象；放量阴烛特别多 = 差一点的现象
- **② 日交易金额达标**：**过去 24 小时**交易金额（1 小时图 收盘价×成交量 滚动累加 24 根）> 门槛 → **选股的 V·流动性用这一项**
  - 门槛在「⑥ Volume → 最低日均交易金额（百万）」，默认 **1.0（= 100 万）**
- **突破**（额外的当根确认）：放量阳烛（当根量 > **交易量均线 MA50** × 1.5）
- **日均交易金额**（只当参考显示）：天图 收盘价×成交量 取 20 天平均 > 门槛
- **加分：烛数**：**放量**阳烛多、**放量**阴烛少（从 C1 起点算到现在，整个 base 期间）— 同样只算量 **超过 MA50** 的蜡烛

## 买点 / 止损 / 盈亏比（仅合并版 SCV_All）

进场三条价位，全部由**末段 C**（最后画出来的那段收缩）＋ buffer 算出来：

| 价位 | 做多 | 做空 |
|------|------|------|
| **买点** | 末段 C 高点 **＋** buffer | 末段 C 低点 **－** buffer |
| **止损** | 末段 C 低点 **－** buffer | 末段 C 高点 **＋** buffer |
| **盈亏比风险** | \|买点 − 止损\| ÷ 买点 × 100%（面板显示这段风险%） | 同左 |

**buffer 怎么算**（「⑦ 买点/止损 Buffer」组里的「资产类型」决定）：

- **股 / 币**：固定 %，按图表周期分三档
  - 天图 **+1%**、时图（≥60 分）**+0.5%**、分图 **+0.25%**
- **汇 / 金 / 指 / 期**：按末段 C 深度的比例
  - buffer% =（末段 C% × 倍数）÷ 2；天·时图倍数 **10%**、分图 **5%**
  - 例：末段 C = 4%，天图 → buffer =（4 × 10%）÷ 2 = **0.2%**

> 买点线（绿）、止损线（红）画在图上；面板「买点 / 止损 / 风险%」同步显示。

## 卖出条件（仅合并版 SCV_All）

分**主动止盈**和**被动跟随**两套，「⑧ 卖出 Sell Trigger」组里可调。

**主动止盈（先到先卖，图上黄线 = 盈亏比目标）**
1. **盈亏比达标**：到 **1:2**（默认，可调）→ 止盈线（黄）
2. **平均盈利的倍数**：到 你的平均单笔盈利 **× 2.5**（默认 5% × 2.5）
3. **高位 + 大波动 + 大量（TP3）**：价格离 50 均线 > **15%**、当根 ATR > 均值 **×1.2**、量 > 均量 **×1.5** 三者同时 → 顶部标 **TP3**
4. **连续阴烛 + 大量（TP4）**：连续 **3** 根阴烛且放量（量 > 均量 ×1.5）→ 标 **TP4**（做空镜像：连续阳烛）

**被动跟随（会做的行情就一直骑，图上橙线 = 移动止盈）**
- 条件：**Stage 2**（做空 Stage 4）且 **Base 还在第 1~2 个** = 主升段，让利润奔跑
- 移动止盈线 = **max(50 均线, 前一个波段底)** **－** buffer；跌破才走

> 「画出止盈 / 移动止盈线」可整组关掉。

## 排错清单（Troubleshooting）

代码只能在 TradingView 的 Pine Editor 里编译。贴上去点「Add to chart」后，
如果出问题，先对照下面这张表。**改不动就把红色错误那一行整句复制发出来。**

### A. 编译报错（编辑器下方出现红字，图上没东西）

| 报错长这样 | 意思 / 怎么改 |
|-----------|-------------|
| `Mismatched input '<something>' expecting <...>` | 复制粘贴时**少贴了几行或多贴了字符**。删掉指标重贴一次整份文件，注意第一行 `//@version=6` 一定要在最顶端。 |
| `Could not find function or function reference 'xxx'` | TradingView 账号的 **Pine 版本被切成旧版**。确认第一行是 `//@version=6`。 |
| `The 'plot' ... cannot be used in a local scope` | 贴的时候某个 `plot` 被误缩进了。所有 `plot / bgcolor / plotshape` 必须顶格。重贴整份即可。 |
| `Pine cannot determine the referencing length of a series` | 已用 `max_bars_back` 处理。若仍出现，把这行报错发出来。 |
| `Script requesting too many securities` | 保持默认设置（RS 用 `SP:SPX`，Stage 周期 `D` + 新图 `240`）。 |

### B. 能加载但显示不对

| 症状 | 原因 / 怎么调 |
|------|-------------|
| **面板显示「新图：看240」** | 这只票**天图还没有 150 均线**（上线不久），Stage 自动切 4 小时。**正常行为，不是 bug。** |
| **切换周期时 Stage 变了** | 不该发生——Stage 固定天图。若真的变了，把两个周期的截图发出来。 |
| **Stage 一直乱跳 / 太敏感** | 「② Stage → 趋平阈值」调大（1.5~2），或「150均线斜率回看K线数」调大（30）。 |
| **完全侦测不到 Contraction（C 段数一直 0）** | ①「⑤ Contraction → 摆动强度」太大 → 调小（3~5）。② C1 没动到 50 均线 → 「50均线触碰容差」调大到 3~4。 |
| **C 段太多/太碎，和手画的对不上** | 「摆动强度」调大（8~10）只抓大波段；或「最小波段深度」调大过滤杂讯。 |
| **某段 C 的 % 和手量的差一点** | 「最小波段深度」可能把它滤掉了（例如 3% 的 C2 卡在 3% 门槛）→ 调到 1.5 或更低。 |
| **RS 一直显示「中性」** | 对比指数和标的不同市场。「③ → 对比指数」换成对应大盘（美股 `SP:SPX`，港股 `HSI`，A股 `SSE:000001`）。 |
| **成交量柱看不到颜色** | 合并版是主图指标，没有成交量柱。要彩色量柱另外加载 `SCV_Volume.pine`（副图）。 |

### C. 面板 / 标签相关

| 症状 | 说明 |
|------|------|
| **面板挡住价格** | 「面板」组 → 「面板位置」换位置；「面板文字大小」选「极小」；或关掉不看的区块。 |
| **标签太多、图很乱** | 历史上每个 base 的 C 段都会留下来当纪录。可关掉「画出每段收缩框」或「显示 C1 三等份区域」。 |

### 反馈 bug 的最快方式

1. **编译错**：复制红色那行的**完整文字**。
2. **判断不对**：给出 **代码 + 时间框架 + 日期 + 期望值 vs 实际值**
   （例：「`AAPL` 天图 2024-03，这里应是 Stage 2，指标却显示 Stage 3」）。
